# 📊 Smart ATS 2.0 - Resume Screening & Candidate Recommendation System

An intelligent recruitment system that analyzes resumes, extracts candidate skills, compares them with job descriptions, and recommends the most suitable candidates using Machine Learning and NLP techniques.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📄 **Resume Parsing** | Extract text from PDF resumes |
| 🧠 **NLP Processing** | Advanced text preprocessing and embeddings |
| 🔧 **Skill Extraction** | Identify technical and soft skills from text |
| 📊 **Candidate Ranking** | Score and rank candidates based on job fit |
| 🔍 **Similarity Analysis** | Compare resumes with job descriptions |
| 🎯 **Recommendation Engine** | Suggest top candidates for each role |
| 🌐 **Web Application** | Interactive interface with Streamlit |

---

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| **Language** | Python 3.13 |
| **Web Framework** | Streamlit, FastAPI |
| **ML/NLP** | scikit-learn, Sentence-Transformers, Transformers |
| **PDF Processing** | PyMuPDF, PyPDF2 |
| **Deep Learning** | PyTorch |
| **LLM Tools** | LangChain, LangGraph, Ollama |
| **Data** | pandas, numpy |

## 📦 Installation

### Prerequisites
- Conda installed
- Git installed
- 4GB+ RAM recommended

### Setup

```bash
# 1. Clone the repository
git clone https://github.com/akshathahr-git/Smart_ATS_2.0_Resume_Screening.git
cd Smart_ATS_2.0_Resume_Screening

# 2. Create Conda environment
conda env create -f environment.yml

# 3. Activate environment
conda activate base
